## 🚀 Projetos

### 🏐 Portal JES
`Python` `Django` `PostgreSQL`

Sistema web para gerenciar os Jogos do Ensino Superior: atletas, atléticas, esportes, grupos, partidas e chaveamento, com login por matrícula e papéis de usuário (admin, capitão, moderador).

- Ideia minha, desenvolvida em equipe com o IFPB
- Software registrado no INPI (BR512026005472-9)

### 📚 IHGP
`Django` `S3` `Gemini Vision`

Redesign do site do Instituto Histórico e Geográfico Paraibano, em produção desde setembro de 2026.

- Ferramenta que cataloga livros a partir de fotos, validando os dados e evitando duplicatas antes de gravar no banco
- Armazenamento dos PDFs digitalizados do acervo em S3

### 🏖️ TrackFieldVolei
`MVP`

Gestão de torneios de vôlei de praia: chaveamento e súmula digital para os árbitros, com os resultados publicados em tempo real para torcida, atletas e organização.
